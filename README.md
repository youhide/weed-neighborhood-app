# Weed Neighborhood: desktop app downloads

The desktop app for **[Weed Neighborhood](https://play.weedneighborhood.com)**, a cozy multiplayer
3D neighborhood game for adults (18+). This repository holds **only the installers**, in its
[Releases](https://github.com/youhide/weed-neighborhood-app/releases); it has no source code.

| Platform | Download (latest version) |
| --- | --- |
| Windows (installer) | [Weed-Neighborhood-Windows-Setup.zip](https://github.com/youhide/weed-neighborhood-app/releases/latest/download/Weed-Neighborhood-Windows-Setup.zip) |
| Windows (portable, no install) | [Weed-Neighborhood-Windows-Portable.zip](https://github.com/youhide/weed-neighborhood-app/releases/latest/download/Weed-Neighborhood-Windows-Portable.zip) |
| Mac with Apple M1 or newer | [Weed-Neighborhood-macOS-AppleSilicon.dmg](https://github.com/youhide/weed-neighborhood-app/releases/latest/download/Weed-Neighborhood-macOS-AppleSilicon.dmg) |
| Mac with Intel | [Weed-Neighborhood-macOS-Intel.dmg](https://github.com/youhide/weed-neighborhood-app/releases/latest/download/Weed-Neighborhood-macOS-Intel.dmg) |

The app is unsigned: the first time, Windows ("Windows protected your PC" → More info → Run anyway)
or macOS (right-click → Open) asks you to confirm.

You can also just play in the browser: <https://play.weedneighborhood.com>
